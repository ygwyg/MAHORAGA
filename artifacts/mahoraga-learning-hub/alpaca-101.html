Broker API

Alpaca is the execution and market data layer.

MAHORAGA does not directly touch an exchange. It talks to Alpaca. Alpaca provides paper accounts, account data, assets, orders, positions, market data, streams, watchlists, CLI tooling, and an MCP server.

Best starting choice

Start on the free Basic plan with paper trading. Upgrade to Algo Trader Plus only when the system specifically needs full SIP stock data, OPRA options data, more WebSocket subscriptions, or higher historical data throughput.

Alpaca objects

The API is a small set of primitives.

Account

Identity, cash, equity, buying power, status, and trading permissions.

Assets

Tradable instruments and metadata: symbol, class, exchange, tradability, fractionability.

Orders

Instructions to buy or sell. MAHORAGA submits orders only after strategy and risk checks.

Positions

Current holdings. A strategy must know what it already owns before opening more risk.

Market data

Quotes, trades, bars, snapshots, historical data, and real-time streams.

Watchlists

Curated symbol sets that help narrow attention and strategy scope.

Paper trading

Paper trading is simulation, not proof.

Alpaca documents paper trading as a real-time simulation that uses market data and simulated fills. It is excellent for learning API behavior, system reliability, and decision quality. It does not fully model market impact, information leakage, queue position, price improvement, fees, or dividends.

What paper trading is good for

Testing credentials, order payloads, dashboard workflows, signal quality, risk limits, alerting, and whether you understand each decision.

What it cannot prove

That a strategy will make money live. Paper fills can be cleaner than real market execution, especially in fast or illiquid markets.

Tooling

CLI and MCP are useful, but they should not bypass safety.

Alpaca CLI

The CLI is useful for operator workflows: inspect accounts, place test orders, check positions, and automate repeatable command-line tasks. Treat it like an admin console.

Alpaca MCP Server

The MCP server lets AI tools interact with Alpaca through structured tools. It can research markets and place orders through natural language clients. For MAHORAGA, it is better as an operator assistant than as the core trading path.

Credential rule

Never paste API keys into chat.

Use environment variables, Cloudflare Worker secrets, or local `.dev.vars` files that are not committed to GitHub. Paper and live Alpaca keys must stay separate. 

ALPACA_API_KEY=paper_key_here
ALPACA_API_SECRET=paper_secret_here
ALPACA_PAPER=true
MAHORAGA_API_TOKEN=dashboard_token_here
